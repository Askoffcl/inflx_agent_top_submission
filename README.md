# Offline Social-to-Lead Agent (AutoStream)

## Run
python main.py

## Features
- Intent detection (rule-based)
- RAG (local JSON knowledge)
- Stateful memory
- Lead capture tool

## Demo Flow
1. Ask pricing
2. Show interest
3. Provide name, email, platform
4. Lead captured

## Note
This version is offline (no API required) for reliable demo.
